# 宠记 PetLog 用户调研 · 问卷与访谈提纲（可分享母版）

> 适用产品：宠记 PetLog（温暖拟人化「AI 养宠健康管家」）；对比参照：宠康AI（专业数据化表达）
> 版本：v1.0 ｜ 更新日期：2026-09-15
> 使用方式：第一部分「定量问卷」可直接搬运至问卷星 / 腾讯问卷投放；第二部分「访谈提纲」供 1v1 深访使用（60 分钟）。

---

## 一、调研背景与目的

宠记 PetLog 定位为 **AI 养宠健康管家**，核心链路为：**随手记录 → AI 健康解读 → 行动建议 / 提醒 → 家人协作**。

本期已上线 / 迭代的关键能力：

| 模块 | 能力 |
| --- | --- |
| 一键快捷记录 | 首页点一下记刷牙 / 铲屎 / 玩耍等，长按补详情，入口可自定义开关 |
| 喂养管理（本期改版重点） | 正餐按「品牌 × 品类代谢能」折算 kcal 与建议区间；保健品 / 营养液独立成「今日补给」并支持周期提醒；统一「记一笔喂养」入口；同一餐次重复记录自动覆盖（upsert），只保留一条 |
| 护理待办 | 驱虫 / 疫苗到期与逾期提醒、一键处理、预约 |
| AI 健康简报 / 管家 | 今日要闻分级（紧急 / 注意 / 正常）、点要闻直达处理、对话式办事 |
| AI 输入与识别 | 「能吃啥」直出结论、拍照 BCS 体况评分、疫苗本 / 病历 OCR、语音转写结构化 |
| 记录沉淀 | 体重曲线、日历、全记录搜索、纪念日、成长瞬间、养护指数、铲屎官等级 |
| 家人共享 | 同住直接加入 / 异地邀请后协作记录；会员体系（无限 AI、多人共享） |

**本期改版解决的两个真实问题：**

1. **展示割裂**：旧版喂养区「热量是数值、保健品 / 营养液是按钮」，三种形态拼在一起。现已改为「正餐热量区在上 + 结构化今日补给清单在下」的分层结构，录入入口收敛为一个主按钮。
2. **重复疑虑**：所有喂养数据只落库一次，健康简报、AI 管家只是读取同一份数据做解读；同时修复了多入口导致的同餐重复记录问题，并在卡片底部明示「共用同一份记录，只记一次」。

### 四个核心问题

1. 养宠人群最高频、最焦虑的健康 / 喂养场景是什么？功能是否打在痛点上？
2. 「记录」的真实负担有多大？快捷记录 vs 精细表单的边界在哪？
3. 用户是否信任并愿意采纳 AI 结论（尤其喂食量、能不能吃、体况判断）？信任前提是什么？
4. 家人协作与付费意愿是否成立，卡点在哪？

### 待验证假设

| 编号 | 假设 |
| --- | --- |
| H1 | 多数人记不住驱虫 / 疫苗周期，逾期提醒是刚需且高频被感知 |
| H2 | 用户愿意为「1 秒快捷记录」持续使用，但不愿天天填精细表单（克数 / 品牌） |
| H3 | 热量 / 克数建议只有在「有据可依（品牌代谢能、体重）」时才被信任 |
| H4 | AI 结论需要「理由 + 可纠错」，否则用户不敢据此行动 |
| H5 | 多人共同照顾一只宠物的家庭，协作是强需求且愿付费 |
| H6（本期新增） | 「正餐 / 补给」分层与统一入口能消除认知割裂；「只记一次」说明能消除对数据重复的疑虑 |

## 二、调研对象、甄别与配额

### 2.1 甄别条件（Screener）

- 目前在养猫和 / 或狗；
- 本人是主要喂养与健康决策者，或共同决策者；
- 近 3 个月内未参加过养宠 App 类调研；
- 本人 / 直系亲属不在宠物医疗、宠物食品、App 研发行业（深访建议加）。

### 2.2 用户画像分层（深访建议四组各覆盖，配额 6–8 人 / 组）

| 组别 | 特征 |
| --- | --- |
| A 组 · 精致养宠型 | 主动学习养宠知识、定期体检、购买宠物保险、记录细致 |
| B 组 · 实用工具型 | 记驱虫疫苗、看症状查资料、追求高效少操作 |
| C 组 · 情感陪伴型 | 爱晒宠、记录成长瞬间、对萌系设计敏感 |
| D 组 · 新手焦虑型 | 养宠 < 2 年、遇到问题频繁搜索、对 AI 问诊有强需求 |

其他配额维度建议：猫 / 狗 ≈ 6:4；年龄段（幼 / 成 / 老）均覆盖；独居养宠与多人照顾 ≈ 5:5。

### 2.3 调研方法与样本量建议

| 方法 | 对象 | 样本量 | 时长 |
| --- | --- | --- | --- |
| 定量问卷 | 问卷星 / 腾讯问卷投放，猫犬主 | ≥ 200 份有效 | 5–8 分钟 |
| 1v1 深访 | A/B/C/D 四组分层 | 8–12 人 | 60 分钟 |
| 可用性任务测试 | 深访内嵌，边操作边出声思考 | 同上 | 含在 60 分钟内 |

# 第一部分 · 用户问卷（定量）

**题型图例**：【单】单选 【多】多选（注明上限）【量】李克特 5 级（1 非常不同意 → 5 非常同意）【NPS】0–10 分 【排】排序题 【开】开放题。带 ★ 为必答；标注【原型】的题目仅请体验过原型的受访者作答。
**投放建议**：D、E、F 模块中的【原型】题可生成「带原型链接版」与「纯概念版」两个问卷版本；无原型体验时用概念描述替代。

## A. 甄别与背景

- **A1★【单】** 你目前是否在养猫 / 狗？　养猫 / 养狗 / 都养 / 都没有（→ 结束并致谢）
- **A2★【单】** 你是它的主要喂养和健康决策者吗？　是 / 共同决策 / 不是（→ 结束）
- **A3★【单】** 你的养宠年限？　< 半年 / 半年–1 年 / 1–2 年 / 2–5 年 / 5 年以上
- **A4【单】** 宠物目前年龄段：　幼年（< 1 岁）/ 成年 / 老年（猫 ≥ 10 岁、犬按品种另算）/ 不清楚
- **A5【单】** 目前养宠只数：　1 只 / 2 只 / 3 只及以上
- **A6【单】** 月均养宠花费（含粮、用品、医疗）：　< 300 / 300–500 / 500–1000 / 1000–2000 / > 2000 元
- **A7【多】** 平时一起照顾它的人：　独自照顾 / 伴侣 / 父母 / 室友 / 孩子 / 其他

## B. 现状与健康焦虑（对应 H1、核心问题 1）

- **B1★【多，≤3】** 照顾宠物时，你最担心 / 最容易出问题的是：　喂多喂少 / 忘记驱虫疫苗 / 喝水太少 / 体重异常变化 / 生病不会判断 / 不知道什么能吃 / 洗澡清洁打理 / 保健品营养品不会选 / 花钱没规划 / 其他
- **B2★【量】** 我经常担心它吃的量或营养不合适。
- **B3★【量】** 我经常忘记或搞不清下次驱虫 / 疫苗的时间。
- **B4【单】** 过去半年它是否出现过健康异常（呕吐拉稀、泌尿、超重、皮肤等）？　出现过，我能自行判断处理 / 出现过，主要靠搜索或问人 / 出现过，直接去了医院 / 没出现过
- **B5【单】** 你判断「今天喂得合不合适」主要靠：　凭感觉 / 看包装喂食说明 / 网上搜攻略 / 问医生 / 用 App 记录计算
- **B6【开】** 最近一次让你为它的健康感到焦虑的事是什么？

## C. 记录行为与负担（对应 H2、核心问题 2）

- **C1★【单】** 你现在会记录喂养 / 健康相关信息吗？　坚持记 / 偶尔记 / 想记但坚持不下来 / 完全不记
- **C2【多】** 目前用什么方式记：　脑子记 / 手机相册 / 备忘录 / Excel 或表格 / 养宠小程序或 App / 智能硬件（喂食器、猫砂盆等）/ 微信收藏或聊天记录
- **C3【单】** 每次「记一笔」你愿意花的最长时间：　点一下即可（< 3 秒）/ 3–10 秒 / 愿意认真填表单 / 看情况
- **C4★【多】** 什么情况下你愿意认真填详细信息（克数、品牌、剂量）：　关心体重 / 减肥期 / 换粮期 / 生病恢复期 / 体检前后 / 喂保健品或药期间 / 永远不想填
- **C5★【量】** 如果点一下就能记完，我会更愿意长期记录。
- **C6★【量】** 如果每次都要输入克数 / 品牌，我很快就会放弃。
- **C7【开】** 你最希望被「自动记录」或「自动提醒」的一件事是？

## D. 喂养体系专项（对应 H3、H6，本期改版重点）

- **D1【单·原型】** 刚才体验中，你最先上手使用的功能是？
- **D2【量·原型】** 首页一键记录（点一下记刷牙 / 铲屎 / 喂食）对我很实用。
- **D3【量·原型】** 「正餐热量 + 建议区间」我看得懂，并且会参考。
- **D4【单·原型】** 看到「今日合计 kcal + 克数 + 建议区间」时，你的第一反应是：　可信，会照做 / 会看，但仅供参考 / 看不懂 / 不关心数字，只关心它吃没吃
- **D5【量·原型】** 保健品 / 营养液单独放在「今日补给」、不和热量混在一起，这样更清楚。
- **D6【量·原型】** 我清楚喂养记录只保存一次，健康简报和 AI 只是在解读同一份数据，不会重复记录。
- **D7【量·原型】** 「同一餐重复记会自动覆盖、加餐每次新增」的规则符合我的直觉。
- **D8【单·原型】** 喂养录入你更偏好：　一个统一入口（记一笔喂养，进去再选类型）/ 食物、保健品、营养液各一个独立按钮 / 无所谓
- **D9【多·原型】** 你最希望周期提醒支持：　体内驱虫 / 体外驱虫 / 疫苗 / 洗澡洗护 / 保健品 / 营养液 / 体检 / 自定义事项
- **D10【单】** 保健品 / 营养液在你心里应该怎么统计？　按次数 / 剂量统计，不算热量（推荐口径）/ 也算成每天摄入的一部分 / 我从来不喂这类
- **D11【开·原型】** 喂养这块还有哪里让你觉得别扭、看不懂或不放心？

## E. AI 能力与信任（对应 H3、H4，核心问题 3）

- **E1【量】** 如果 App 根据宠物体重和粮食品牌代谢能告诉我该喂多少克，我愿意照做。
- **E2【量】** AI 说某种食物能吃 / 不能吃，我会直接相信。
- **E3【多】** 什么情况下你才敢相信 AI 的健康建议：　给出来源 / 理由 / 结合我家宠物的档案 / 能一键追问或转人工医生 / 识别后可手动修改 / 有其他用户验证 / 有执业兽医背书
- **E4【量·原型】** 「能吃啥」直接给结论 + 怎么喂，比我自己去查攻略更好。
- **E5【量·原型】** 拍照测体况（BCS）、拍疫苗本自动识别录入，我愿意用。
- **E6【单】** 如果 AI 识别错了（如 OCR 录错疫苗日期），你期望：　必须能让我手动修改 / 录入时给我二次确认 / 错一次我就不再相信它 / 无所谓
- **E7【量】** 我更信任能说清「为什么这么建议」的 AI，而不是只甩给我一个结论。
- **E8【NPS】** 你有多大可能把「会给健康建议的养宠 AI 管家」推荐给身边养宠的朋友？（0–10）
- **E9【开】** 你最希望 AI 替你做的一个决定 / 一件事是什么？

## F. 家人协作（对应 H5、核心问题 4）

- **F1【单】** 你家是否多人轮流照顾 / 喂食？　是，每天都多人参与 / 偶尔有人帮忙 / 基本我一人全包
- **F2【量】** 多人各记各的、信息不同步，确实让我困扰。
- **F3【量·原型】** 家人共用一份记录、谁喂了都能看到，对我很有价值。
- **F4【单·原型】** 两种加入方式哪种更符合你的情况：　同住家人填昵称直接加入 / 异地家人发邀请、对方接受后加入
- **F5【多】** 协作中你最怕出现：　重复喂食 / 重复给药 / 看不到对方的记录 / 权限不清 / 被消息打扰 / 其他

## G. 付费意愿

- **G1【量】** 如果它真能帮我少跑医院、不遗漏驱虫疫苗，我愿意付费。
- **G2【单】** 你能接受的付费模式：　免费 + 广告 / 一次性买断 / 按月订阅 / 按年订阅 / 只愿用免费版
- **G3【单】** 可接受的会员价格（每年）：　< 30 / 30–68 / 68–128 / 128–198 / > 198 元
- **G4【多】** 最愿意为之付费的能力：　无限 AI 问答 / 多人共享 / 拍照体况与 OCR / 深度健康周报 / 疫苗提醒与预约 / 执业兽医在线问诊 / 成长纪念相册

## H. 优先级与开放

- **H1★【排】** 请选出你最希望优先做好的 3 项并排序：　① 快捷记录　② 喂食量与热量　③ 驱虫疫苗提醒　④ AI 健康简报　⑤ 能吃啥查询　⑥ 拍照 / 语音智能录入　⑦ 体重与体况　⑧ 家人共享　⑨ 成长纪念 / 日记
- **H2【开】** 整体体验下来最满意的一点是？
- **H3【开】** 最想吐槽、或最影响你继续使用的一点是？
- **H4【开】** 如果它只能保留一个功能，你希望是什么？

# 第二部分 · 1v1 深度访谈提纲（定性，60 分钟）

**形式**：腾讯会议 / 线下面访，屏幕共享 + 录屏；请用户「边操作边说出来」（出声思考法）。
**物料**：宠记可交互原型、宠康AI 原型、录屏授权书、功能评分卡。
**顺序平衡**：一半受访者先看宠康AI，一半先看宠记，消除顺序偏差。

## 时间安排

| 时段 | 环节 | 时长 |
| --- | --- | --- |
| 0 | 暖场与背景 | 5 min |
| 1 | 真实的一天与健康焦虑 | 8 min |
| 2 | 记录行为与负担（含操作任务） | 10 min |
| 3 | 喂养体系改版专项（重点） | 10 min |
| 4 | AI 信任与纠错 | 10 min |
| 5 | 两产品表达对比 & 分类体系 | 10 min |
| 6 | 协作、付费与收尾 | 7 min |

## 第 0 幕 · 暖场（5 min）

1. 介绍一下你家主子：品种、年纪、绝育情况、谁主要管、一天的照顾流程大概是怎样的？
2. 之前用过哪些养宠 / 宠物健康类 App 或小程序？最常用什么、最不满意什么？

> 说明：接下来看到的是两款还在设计中的可交互原型，部分功能不完整，任何觉得别扭的地方都欢迎直接说，没有对错。

## 第 1 幕 · 真实的一天与健康焦虑（8 min）

1. 从早到晚，喂粮、换水、铲屎、护理分别怎么做、谁来做？
2. 最近一次「担心它健康」是什么时候？发生了什么，你怎么处理的？
3. 你怎么判断喂多了还是喂少了？
4. 驱虫、疫苗、体检的时间是怎么记的？有没有忘过？忘了之后有什么后果？
5. 它出现呕吐、拉稀、不吃饭这类异常时，你的第一反应是什么？（搜索 / 问群友 / 问医生 / 直接去医院）

## 第 2 幕 · 记录行为与负担（10 min，对应 C / D2）

1. 现在会做任何形式的记录吗？**可以翻开手机给我看看吗？**（相册、备忘录、购物记录、微信群都行）
2. **操作任务**：
   - 任务 A：用首页「一键记录」点一下记一次铲屎 / 刷牙；
   - 任务 B：用「记一笔喂养」完整记一次正餐。
3. 追问：哪一步让你迟疑或觉得多余？克数和品牌你平时真的知道吗？
4. 什么信息你愿意每次都填，什么是绝对不想填的？长按补详情这个隐式入口你能发现吗？

## 第 3 幕 · 喂养体系改版专项（10 min，对应 D / H3 / H6，本期重点）

> 展示新版喂养卡：上部「正餐 · 供能热量」，下部「今日补给 · 保健品 / 营养液」，底部统一「记一笔喂养」按钮与「只记一次」说明。

1. 不看任何提示，先描述这张卡片在告诉你什么？
2. 正餐热量区（kcal、克数、建议区间）你看得懂吗？会照着调整喂食量吗？什么前提下你才信这个克数？（体重 / 包装代谢能 / 兽医背书）
3. 保健品、营养液你平时喂不喂？怎么记剂量？你觉得它们该不该算进「热量」？
4. 把保健品 / 营养液从「按钮」改成下方的补给清单（含周期铃铛标记），和旧版相比哪种更清楚？
5. **重复疑虑探针**：你在这里记了一顿饭，又去「AI 健康管家」里说了一遍，你觉得数据会记几次？看到底部「共用同一份记录，只记一次」这句话，疑虑消除了吗？你希望系统再用什么方式证明没重复？
6. **同餐覆盖探针**：早餐你先用大碗快捷记了一次，后来又在表单里补了品牌和克数，你期望出现两条记录还是一条被更新？（验证 upsert 规则是否符合直觉；加餐场景另问）
7. 你在什么情况下会每天、每顿都认真记录摄入？为什么大多数时候不记？

## 第 4 幕 · AI 信任与纠错（10 min，对应 E）

依次体验：**今日简报（分级要闻）→ 问管家 → 能吃啥直出 → 拍照 BCS → OCR 疫苗本**。

1. 今日简报里「紧急 / 注意 / 正常」三级，你会先看哪个？点要闻直达处理，路径顺吗？
2. 「能吃啥」直接给「可以吃 / 不能吃 + 怎么喂」的结论，你信吗？你想同时看到什么依据？
3. 自动预填「海乐妙 1 片」这种细节，你觉得贴心还是不放心？填错了你能发现、能改吗？
4. 如果它说错了一次，你还会继续用吗？错到什么程度你会彻底不信任？
5. **情境题**：AI 明确提示巧克力不能喂，但家里长辈已经喂了一小块，你期望它此刻怎么帮你？（观察从「结论」到「行动 + 就医判断」的期待）
6. 语音一句话自动归类记录，你会在什么场景用？担心识别错类型吗？你觉得麦克风按钮放在哪里最顺手、最容易第一时间找到？

## 第 5 幕 · 两种表达对比与分类体系（10 min）

### 5.1 定位感知与设计表达（宠康AI 专业数据风 vs 宠记温暖萌系）

1. 分别用一句话说说这两个 App 是帮你解决什么问题的？你能感觉到它们都想做「AI 健康管家」吗？
2. 宠康AI 的「健康分 85 分」，你觉得是什么意思？会关注并因此改变行为吗？数据化表达让你更信任还是有距离感？
3. 宠记的拟人问候「我已经 7 天没驱虫啦」vs 直接文案「驱虫已逾期 7 天」，你更喜欢哪种？
4. 连续打卡、铲屎官等级这类游戏化元素，会激励你还是觉得幼稚？
5. 若融合成一个产品：视觉要专业风 / 萌系 / 混合？语气要直接专业 / 拟人贴心 / 按场景切换？功能上最不能少的三个、交互上最不能少的一个是什么？
6. 「管家」做到什么程度，才算真的「管」到了你家宠物的健康？（主动发现 / 替你做决定 / 只做提醒和记录）

### 5.2 信息架构与分类体系

1. 首页第一眼看到什么？你认为首页最重要的信息应该是什么？
2. 底部 Tab「今天 / 记录 / 我的」符合习惯吗？「今天」这个名字你点之前知道里面是什么吗？
3. 记录一条驱虫，你认为最少几步？哪些字段必填、哪些可省？
4. 宠康AI 的「用药 / 护理 / 医疗 / 健康 / 体重」五大类 vs 宠记的「事项 / 成长」+「日常 / 基础健康 / 清洁洗护 / 打理清扫 / 其他」标签，哪种更符合你的思维？
5. 边界探针：驱虫算「用药」吗？洗澡算清洁还是日常？换猫砂算「打理清扫」吗？「呕吐」应该去哪一类找？生理期 / 发情期两个产品放得下吗？
6. 查历史时你更多是找「上次驱虫是什么时候」（按类型）还是「上周发生了什么」（按时间）？手风琴分类展开 vs 纯时间线你更习惯哪个？
7. 「自定义分类」（如过敏记录、饮食调整）你需要吗？

## 第 6 幕 · 协作、付费与收尾（7 min）

1. 家里多人照顾时出现过重复喂、重复给药吗？一份共享记录能解决吗？你担心权限或打扰问题吗？
2. 如果有会员，什么功能值得你付钱？每年多少钱可接受？（追问价格锚点）
3. 如果 AI 背后能接通真实执业兽医图文 / 视频问诊，你愿意付费吗？什么价位？
4. 功能评分卡打分（见附录 A），并追问：只能保留 3 个功能留哪 3 个？有没有两个产品都没做、但你特别想要的？
5. 你会把它推荐给养宠朋友吗？理由是什么？（对应 NPS）
6. 还有什么没说到但你觉得重要的？如果产品团队就在面前，你最想说什么？后续新版本测试愿意继续参加吗？

## 附录 C · 执行注意事项

1. **不引导**：避免「您不觉得这个功能很方便吗」这类倾向性提问，改用「你怎么看这个功能」。
2. **看行为而非观点**：「我会用」≠ 真的会用，重点记录自由探索阶段的真实点击路径与卡点。
3. **沉默是金**：受访者停顿时等 5 秒，不急着补充。
4. **连问为什么**：出现「好 / 不好 / 还行」时至少追问一次具体原因与最近一次真实经历。
5. **顺序平衡**：两产品展示顺序轮换。
6. **标记矛盾**：嘴上认可但操作中绕过的功能要显式标记。
7. **原型免责声明**：开场说明「可交互原型、功能不完整、欢迎吐槽」。
